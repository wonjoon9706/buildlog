- [x] 프론트엔드와 백엔드를 분리해서 개발
- [x] 프론트엔드: React
- [x] 백엔드: Python과 FastAPI
- [x] 운영 데이터베이스: Supabase 데이터베이스

- [x] React는 FastAPI를 통해서만 개인 데이터 사용

## 10. Phase 1 시작 전 사용자 준비

Phase 1의 React·FastAPI·SQLite3 기본 환경 구성은 사용자가 제공할 비밀값 없이 시작할 수 있습니다.

Supabase 연결 확인 전에는 다음 항목이 필요합니다.

- Supabase 프로젝트
- Supabase 데이터베이스 연결 문자열
- 연결 문자열을 저장할 로컬 `backend/.env`

연결 문자열과 비밀번호는 채팅이나 문서에 붙여 넣지 않습니다. Supabase 프로젝트가 아직 없어도 SQLite3 기반 테스트 환경부터 진행할 수 있으므로 Phase 1 시작을 막지 않습니다.
